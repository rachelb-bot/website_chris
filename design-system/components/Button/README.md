# Button

Buttons start an action, and there are only two kinds. **primary** (`action` fill, `on-action` text) is the one thing the section is for, usually *Request a quote*; use one per view. **outline** (a `text` border) is the alternative, usually *Give us a call*. Use the standard words: Request a quote, Give us a call, Send a message. Pass `href` for links (it renders an anchor) and `icon` for a leading illustration. `size="lg"` is for heroes and the emergency call button. Minimum height is `size-tap`.

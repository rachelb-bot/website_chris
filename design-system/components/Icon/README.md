# Icon

Icon draws one of the brand's spot illustrations by name. They are decorative: always put the meaning in text next to them. Size them at 22 (inline ticks), 40 (lists), 56–64 (tiles) or larger inside a Medal. The line colour follows `--ic-line`; set it to `on-night-soft` when a line-only icon sits directly on night. The full set is in the Icons asset group as standalone SVGs for print.

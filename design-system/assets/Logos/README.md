# Logos

- `badge-off80.svg` / `badge-off80.png`: the primary logo. Full colour only; outlined lettering, prints without fonts. Minimum 48px (0.75 in) across.
- `lockup-light.svg`: badge plus the OFF 80 / ELECTRIC wordmark, for paper, white and tan grounds (night and rust lettering).
- `lockup-dark.svg`: the same for night grounds (on-night and tan lettering).
- `mark.svg`: the simplified badge for sizes under 48px: browser tabs, app icons, small embroidery.
- `badge-northern-spark.svg` / `.png`: the original Northern Spark badge, kept for reference and continuity. Not for new materials.

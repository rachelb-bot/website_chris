# Icons

Spot illustrations on a 64px grid: a 2.5px `night` line (#16302F) with flat fills of tan (#E7CF97), rust (#B9481F), warm white (#FBF8F1) and night-2 (#1F403E). Colours are baked in, so they work in any app; on night grounds place them inside a medallion. One per service, one per guide topic (costs, safety, outages, ev-solar, older, rules), and small ones for facts and contact (check, pin, clock, permit, tower, mountain, phone, mail, quote).
